(Аналогично можно убрать перемешивание по рядам (is_randomize_rows))

TABLE
| Тип ЭМ волн: | 0.01 нм | 100 нм | 500 нм | 0.1 мм | 100 м |

| Инфракрасное излучение | 0 | 0 | 0 | 1 | 0 |
