# Шаг SPACE - задача на пропуски

lesson = 2253457

## Шаблон

[Задача на пропуски](https://stepik.org/lesson/385339/step/1)

```
## SPACE Заголовок

Текст перед пропуском с выпадающим списком <[правильный ответ 1], [правильный ответ 2], *[неправильный ответ]>

Текст перед пропуском без выпадающего списка (варианты ответов не показываются, указываются только верные) <[правильный ответ 1], [правильный ответ 2]>


CONFIG
case_sensitive: false
visual_feedback: false
partial_correct: false
score: 1
```

У этого типа шага есть два типа пропусков:
1. Выпадающий список. Нужно отметить знаком "*" неправильные ответы
2. Нет выпадающего списка. Тогда нужно записать только правильные варианты

Доступны следующие дополнительные параметры:

* case_sensitive
Регистр ответа должен совпадать: регулирует точность совпадения введенного ответа с заданным правильным ответом;
По умолчанию нет
* visual_feedback
Показывать верные и ошибочные ячейки (детализировать фидбек учащимся): подсвечивает для учащихся верные и неверные ответы: красным крестом отмечаются неверно заполненные пропуски, зеленой галочкой – верные.
По умолчанию нет
* partial_correct
Оценка зависит от числа верных ячеек: позволяет начислить учащемуся частичный балл в зависимости от того, как много пропусков он заполнил верно.
По умолчанию нет

В вариантах ответа можно использовать ], но тогда нужно экранировать \\]

## SPACE Без выпадающего списка

Поэму "Медный всадник" написал <[Пушкин], [А.С. Пушкин], [А. С. Пушкин], [Александр Сергеевич Пушкин]>

## SPACE Выпадающий список

Поэму "Кому на Руси жить хорошо" написал <*[Пушкин], *[Тургеньев], [Некрасов]>

## SPACE Смешанный вариант

<[], *[void], [int], *[float]> main <[()], *[{}], *[<>], *[[\]]>
{
    <[printf]>("Hello world!");
    return 0;
}

## SPACE case_sensitive

Если нужно, чтобы регистр ответа совпадал:

Самый маленький по площади материк - <[Австралия]>.
Пустыня <[Сахара]> - самая большая жаркая пустыня в мире.
Столица Японии - <[Токио]>.
Столица Канады - <[Оттава]>.

CONFIG
case_sensitive: true

## SPACE visual_feedback

Если хочется, чтобы было видно, где ошибки

Биология наука о <*[растениях], *[животных], *[грибах], [жизни]>.
У человека нормальный набор хромосом состоит из <[23], *[46], *[32], *[18]> пар.
К прокариотам относятся <[бактерии], [археи], *[грибы], *[вирусы], *[растения]>.
В молекуле ДНК азотистое основание аденин комплементарно <*[гуанину], [тимину], *[цитозину], *[урацилу]>.
Органоид, отвечающий за модификацию и упаковку веществ в клетке, - это <*[митохондрия], [аппарат Гольджи], *[рибосома], *[ядро]>.

CONFIG
visual_feedback: true

## SPACE partial_correct

Если хочется, чтобы начислялись баллы за частично верный ответ

Первая мировая война началась в <[1914], *[1939], *[1905], *[1917]> году.
Крупнейшее восстание рабов в Древнем Риме под предводительством Спартака произошло в <*[I веке н.э.], [I веке до н.э.], *[II веке н.э.], *[V веке до н.э.]>.
Первый император в истории России — это <*[Иван Грозный], [Пётр I], *[Иван III], *[Николай II]>.
Холодная война - это период противостояния между <*[Россией и Францией], [СССР и США], *[Германией и Англией], *[Китаем и Японией]>.

CONFIG
partial_correct: true
