### Шаг GENNUMBER (численная задача со случайной генерацией условия)

Шаг типа `GENNUMBER` предлагает пользователю решить задачу, в которой числовые значения генерируются случайным образом при каждой попытке. Система автоматически проверяет ответ по формуле, указанной автором.

> **Общие поля** (`id`, `lesson`, `position`, `status`, `text`, `video`, `viewed_by`, `passed_by`, `discussions_count`, `num_grades`) описаны в разделе ["Текстовые шаги в Stepik"](https://stepik.org/lesson/2281192/step/1?unit=2315580). Здесь рассматриваются только поля, специфичные для задач со случайной генерацией.

#### Пример шага GENNUMBER из API Stepik

```json
{
  "id": 9939791,
  "lesson": 2330913,
  "position": 2,
  "status": "ready",
  "block": {
    "name": "random-tasks",
    "text": "",
    "video": null,
    "options": {},
    "subtitle_files": [],
    "is_deprecated": false,
    "source": {
      "task": "В саду цветут яблони и груши.\nПчела опылила \\x цветочков, а шмель \\y.\nСколько цветочков они опылили вместе?\n",
      "solve": "x+y",
      "max_error": "0",
      "ranges": [
        {
          "variable": "x",
          "num_from": "1",
          "num_to": "20",
          "num_step": "1"
        },
        {
          "variable": "y",
          "num_from": "1",
          "num_to": "15",
          "num_step": "1"
        }
      ],
      "combinations": "266"
    },
    "subtitles": {},
    "tests_archive": null,
    "feedback_correct": "",
    "feedback_wrong": ""
  },
  "cost": 2,
  "viewed_by": 42,
  "passed_by": 35,
  "correct_ratio": 0.833,
  "discussions_count": 3,
  "num_grades": [0, 0, 0, 1, 2]
}
```

#### Специфичные поля шага GENNUMBER

`block.name` : Всегда равен `"random-tasks"` — определяет тип шага.

`block.source` : **Самый важный объект, в котором хранятся все данные для генерации и проверки задачи.**

* `task` : Текст условия задачи. **Переменные обозначаются с обратным слешем**, например `\x`, `\y`, `\r`. При каждой попытке переменные заменяются на случайные значения из указанных диапазонов.
* `solve` : **Формула для вычисления ответа.** Может содержать математические операции (`+`, `-`, `*`, `/`, `()`).
* `max_error` : **Допустимая погрешность.** Пользователь получит баллы, если его ответ попадает в интервал `[solve - max_error, solve + max_error]`. Если `max_error = "0"`, требуется точное совпадение.
* `ranges` : Массив объектов, описывающих каждую переменную, используемую в задаче.
  * `variable` : Имя переменной (например, `"x"`, `"y"`, `"r"`).
  * `num_from` : Начальное значение диапазона (включительно).
  * `num_to` : Конечное значение диапазона (включительно).
  * `num_step` : Шаг генерации значений.
* `combinations` : Общее количество возможных комбинаций переменных (вычисляется автоматически).

#### Другие варианты использования поля `source`

1. **Задача с погрешностью**
   Если ответ требует указания погрешности (например, вычисление длины окружности с `π ≈ 3.14`).

   ```json
   "source": {
     "task": "Пчела облетела яблоню по траектории с радиусом \\r м\nКакой путь пролетела пчела в сантиметрах?",
     "solve": "2 * 3.14 * 100 * r",
     "max_error": "2.0",
     "ranges": [
       {
         "variable": "r",
         "num_from": "0.2",
         "num_to": "2",
         "num_step": "0.1"
       }
     ]
   }
   ```
2. **Несколько переменных**
   В задаче может быть произвольное количество переменных.

   ```json
   "source": {
     "task": "Мельница работала \\h часов в день и намолола \\a ц муки за 6 дней.\nСколько часов нужно работать, чтобы за 8 дней намолоть \\b т муки?",
     "solve": "(6 * b * 10) / (8 * a) * h",
     "max_error": "0",
     "ranges": [
       {"variable": "h", "num_from": "1", "num_to": "24", "num_step": "1"},
       {"variable": "a", "num_from": "100", "num_to": "300", "num_step": "100"},
       {"variable": "b", "num_from": "0", "num_to": "100", "num_step": "1"}
     ]
   }
   ```
3. **Фиксированное значение переменной**
   Если `num_from == num_to`, переменная имеет фиксированное значение.

   ```json
   "ranges": [
     {"variable": "pi", "num_from": "3.14", "num_to": "3.14", "num_step": "1"}
   ]
   ```
