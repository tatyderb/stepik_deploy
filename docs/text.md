# Текстовые шаги в Stepik

## Что такое текстовый шаг

Текстовый шаг — это база для любой теории. В нём нет заданий, только информация: лекции, пояснения, примеры кода, формулы и картинки.

Создать такой шаг можно в визуальном редакторе на сайте или в HTML.  Все приёмы оформления, которые работают в текстовом шаге (заголовки, списки, таблицы, формулы), точно так же работают и в условиях задач.

Пример текстового шага из API Stepik:

```json
{
  "id": 8127255,
  "lesson": 1945916,
  "position": 1,
  "status": "ready",
  "block": {
    "name": "text",
    "text": "<h2>Простой текст</h2>\n<p>Первый абзац.</p>\n<p>Второй абзац.\nИз двух строк.</p>",
    "video": null,
    "options": {},
    "subtitle_files": [],
    "is_deprecated": false,
    "source": {},
    "subtitles": {},
    "tests_archive": null,
    "feedback_correct": "",
    "feedback_wrong": ""
  },
  "cost": 0,
  "viewed_by": 74,
  "passed_by": 74,
  "discussions_count": 1,
  "num_grades": [0, 0, 0, 0, 1]
}
```

## Главные поля, которые нужно знать

### 1. Идентификация шага


| Поле   | В примере | Что это                                            |
| ---------- | ----------------- | -------------------------------------------------------- |
| `id`       | 8127255           | Уникальный номер шага                 |
| `lesson`   | 1945916           | ID урока, где лежит шаг                  |
| `position` | 1                 | Какой по счёту в уроке                 |
| `status`   | "ready"           | Опубликован (`ready`) или черновик |

### 2. Блок (block)

**`name: "text"`** - тип шага

**`text: ...`** - Здесь лежит HTML-код с содержанием шага.

Какие именно возможности HTML поддерживает Stepik можно посмотреть [здесь](https://help.stepik.org/article/54794).

**`video: null`** - видео не прикреплено. Может быть ссылка на видео, если нужно.

**`options: {}`** — пустой объект. В тестах тут лежат настройки (перемешивание и т.п.), а для текста ничего нет.

**`subtitle_files: []`** — пустой массив. Если бы было видео с субтитрами, они были бы здесь.

**`is_deprecated: false`** — "не устарел". Если `true` — шаг старый и его скоро удалят.

**`source: {}`** — пустой объект. В тестах тут лежат варианты ответов, правильные ответы. Для текста ничего нет.

**`feedback_correct`** и **`feedback_wrong`** — комментарии, которые видит студент после ответа. В текстовых шагах не используются.

### 3. Статистика


| Поле            | В примере | Что означает                                                  |
| ------------------- | ----------------- | ------------------------------------------------------------------------ |
| `viewed_by`         | 74                | Сколько человек открыли                             |
| `passed_by`         | 74                | Сколько прошли (для текста = просмотрам) |
| `discussions_count` | 1                 | Сколько комментариев оставили                 |

### 4. Реакции

![](https://secure.usedesk.ru/upload/gimages/165119/2025_10_15/VKkOiGY6MK3s.png)

```json
"num_grades": [0, 0, 0, 1, 1]
```

Это массив из 5 чисел. Каждое число показывает, сколько раз поставили соответствующий смайлик под шагом:


| Индекс | Смайлик                                             | Что означает |
| ------------ | ---------------------------------------------------------- | ----------------------- |
| `[0]`        | ![icon](https://stepik.org/static/frontend/feedback/1.svg) | Ужасно            |
| `[1]`        | ![icon](https://stepik.org/static/frontend/feedback/2.svg) | Плохо              |
| `[2]`        | ![icon](https://stepik.org/static/frontend/feedback/3.svg) | Нормально      |
| `[3]`        | ![icon](https://stepik.org/static/frontend/feedback/4.svg) | Хорошо            |
| `[4]`        | ![icon](https://stepik.org/static/frontend/feedback/5.svg) | Отлично          |

В нашем примере:

* `num_grades[3] = 1` → одна реакция ![icon](https://stepik.org/static/frontend/feedback/4.svg)
* `num_grades[4] = 1` → одна реакция ![icon](https://stepik.org/static/frontend/feedback/5.svg)
* Остальные смайлики никто не ставил

### 5. Баллы


| Поле | В примере | Что означает                                                                                     |
| -------- | ----------------- | ----------------------------------------------------------------------------------------------------------- |
| `cost`   | 0                 | Баллы за выполнение шага. Обычно у текстовых шагов 0 баллов |

Для текстовых шагов можно поставить score отличное от 0, если загружать шаг через API, например, с помощью StepKit. Тогда переход на шаг учеником будет начислять ему баллы. И в журнале успеваемости будут так же отмечены текстовые шаги с пометкой зачислены за них баллы или нет.

*Иногда бывает полезно так делать в курсе, если прочесть материал для студента - действительно работа. Например, курсы для студентов, у который русский как иностранный. Обычно оставляем текстовые шаги без score.*
