### Шаг NUMBER Stepik

Шаг типа `NUMBER` (численная задача) предлагает студенту ввести число в качестве ответа. Система автоматически проверяет ответ, сравнивая его с эталонным значением и, при необходимости, учитывая допустимую погрешность.

> **Общие поля** (`id`, `lesson`, `position`, `status`, `text`, `video`, `viewed_by`, `passed_by`, `discussions_count`, `num_grades`) описаны в разделе ["Текстовые шаги в Stepik"](https://stepik.org/lesson/2281192/step/1?unit=2315580). Здесь рассматриваются только поля, специфичные для численных задач.

#### Пример шага NUMBER из API Stepik

```json
{
  "id": 8210387,
  "lesson": 1950069,
  "position": 2,
  "status": "ready",
  "block": {
    "name": "number",
    "text": "<h2>Целое число</h2>\n<p>Чему равно 2 + 2 ?</p>",
    "video": null,
    "options": {},
    "subtitle_files": [],
    "is_deprecated": false,
    "source": {
      "options": [
        {
          "answer": "4.0",
          "max_error": "0.0"
        }
      ],
      "sample_size": 1,
      "is_options_feedback": false
    },
    "subtitles": {},
    "tests_archive": null,
    "feedback_correct": "",
    "feedback_wrong": ""
  },
  "cost": 2,
  "viewed_by": 24,
  "passed_by": 16,
  "correct_ratio": 0.944444444444444,
  "discussions_count": 1,
  "num_grades": [0, 0, 0, 0, 1]
}
```

#### Специфичные поля шага NUMBER

`block.name` : Всегда равен "number" — определяет тип шага.

`block.source`: **Самый важный объект, в котором хранятся данные для проверки ответа.**

* `options`: Массив объектов, где каждый объект — это один правильный ответ. В данном случае массив содержит один ответ.
* `answer`: `"4.0"` — **Эталонный ответ**. Хранится в строковом формате.
* `max_error`: `"0.0"` — **Допустимая абсолютная погрешность**. Поскольку она равна нулю, система будет проверять точное совпадение с ответом `"4.0"`. Тоже хранится в строковом формате.
* `sample_size`: `1` — Количество правильных ответов в массиве `options`.
* `is_options_feedback`: `false` — Флаг, указывающий, показывать ли студенту индивидуальную обратную связь для каждого варианта ответа (в данном случае не актуален, так как вариант один).
* `feedback_correct` и `feedback_wrong`: Пустые строки. Здесь можно было бы разместить комментарии для студента, которые он увидит после правильного или неправильного ответа.

**Баллы (cost)**

`cost`: `2` — **Количество баллов за правильное выполнение шага.** В отличие от текстовых шагов, у численных задач всегда есть баллы. Студент, ответивший `"4.0"`, получит 2 балла.

**Статистика**

`correct_ratio`: `0.9444...` — Доля правильных ответов среди всех попыток.

### Другие варианты использования поля `source`

Поле `source` может быть более сложным, чем в приведённом примере.

1. **Один ответ с погрешностью**
   Если задача требует ответа с погрешностью (например, результат деления 1/3), поле `max_error` используется для указания допустимого отклонения.

   ```json
   "options": [
     {
       "answer": "0.333",
       "max_error": "0.01"
     }
   ],
   "sample_size": 1
   ```
   Это значит, что ответ студента будет считаться верным, если он попадает в интервал `[0.323, 0.343]`.
2. **Несколько правильных ответов**
   В задаче может быть несколько верных ответов. Например, для уравнения `sin(x) = x^2`.

   ```json
   "options": [
     {
       "answer": "0.0",
       "max_error": "0.0"
     },
     {
       "answer": "0.87",
       "max_error": "0.1"
     }
   ],
   "sample_size": 2
   ```
   Студент получит баллы, если его ответ совпадет с любым из указанных в массиве `options`.
