### Шаг STRING (ввод строки)

В этом типе задач пользователю предлагается написать число, слово или текст, которые затем проверяются по шаблону, заданному автором задания.

> **Общие поля** (`id`, `lesson`, `position`, `status`, `text`, `video`, `viewed_by`, `passed_by`, `discussions_count`, `num_grades`) описаны в разделе ["Текстовые шаги в Stepik"](https://stepik.org/lesson/2281192/step/1?unit=2315580). Здесь рассматриваются только поля, специфичные для строковых задач.

#### Примеры шага STRING из API Stepik

**Пример 1: Простая проверка с учётом регистра**

```json
{
  "id": 8491277,
  "lesson": 1977210,
  "position": 3,
  "status": "ready",
  "block": {
    "name": "string",
    "text": "<h2>Демонстрация опции CONFIG</h2>\n<p>Назовите столицу России</p>",
    "source": {
      "pattern": "Москва",
      "use_re": false,
      "match_substring": false,
      "case_sensitive": true,
      "is_text_disabled": false,
      "is_file_disabled": true
    }
  },
  "cost": 1
}
```

**Пример 2: Проверка по регулярному выражению**

```json
{
  "id": 8496387,
  "lesson": 1977210,
  "position": 5,
  "status": "ready",
  "block": {
    "name": "string",
    "text": "<h2>Регулярные выражения</h2>\n<p>Напишите север или юг</p>",
    "source": {
      "pattern": "север|юг",
      "use_re": true,
      "match_substring": false,
      "case_sensitive": false,
      "is_text_disabled": false,
      "is_file_disabled": true
    }
  },
  "cost": 1
}
```

#### Специфичные поля шага STRING

* **`block.name`** : `"string"` — Тип шага. Для строковой задачи всегда `"string"`.
* **`block.source`** : Объект, содержащий данные для проверки ответа.
  * `pattern` : `"Москва"` — Эталонный ответ. Может быть обычной строкой или регулярным выражением.
  * `use_re` : `false` / `true` — Интерпретировать ли `pattern` как регулярное выражение.
  * `match_substring` : `false` — Искать ли вхождение подстроки. Если `false` — требуется полное совпадение.
  * `case_sensitive` : `true` / `false` — Учитывать ли регистр при сравнении.
  * `is_text_disabled` : `false` — Запретить ввод ответа в текстовое поле.
  * `is_file_disabled` : `true` — Запретить отправку файла с ответом.
* **`cost`** : `1` — Баллы за выполнение шага.

#### Комбинации `is_text_disabled` и `is_file_disabled`


| `is_text_disabled` | `is_file_disabled` | Результат                                                                                          |
| ------------------ | ------------------ | ----------------------------------------------------------------------------------------------------------- |
| `false`            | `true`             | Только текстовый ввод (по умолчанию для бесплатных курсов) |
| `true`             | `false`            | Только загрузка файла                                                                    |
| `false`            | `false`            | Текст или файл                                                                                  |

#### Статистика


| Поле        | В примере | Описание                                                                               |
| --------------- | ----------------- | ---------------------------------------------------------------------------------------------- |
| `correct_ratio` | `0.846` / `0.429` | Доля правильных ответов среди всех попыток.               |
| `passed_by`     | `10` / `5`        | Количество пользователей, успешно решивших задачу. |
