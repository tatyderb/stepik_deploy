### Шаг SORT (задача на сортировку/упорядочивание)

В этом типе задач пользователю предлагается расположить элементы в правильном порядке. Система автоматически проверяет порядок, сравнивая его с эталонным.

> **Общие поля** (`id`, `lesson`, `position`, `status`, `text`, `video`, `viewed_by`, `passed_by`, `discussions_count`, `num_grades`) описаны в разделе ["Текстовые шаги в Stepik"](https://stepik.org/lesson/2281192/step/1?unit=2315580). Здесь рассматриваются только поля, специфичные для задач на сортировку.

#### Пример шага SORT из API Stepik

```json
{
  "id": 9485450,
  "lesson": 2074851,
  "position": 2,
  "status": "ready",
  "block":{
    "text":"Вы можете изменить условие задания в этом поле и указать настройки ниже.",
    "name":"sorting",
    "video":null,
    "options":null,
    "source": {
      "is_html_enabled":true,
      "options": [
        {
          "text":"One"
        },
        {
          "text":"Two"
        },
        {
          "text":"Three"
        }
      ]
    }
  },
  "cost": 2,
  "viewed_by": 15,
  "passed_by": 12,
  "correct_ratio": 0.8,
  "discussions_count": 0,
  "num_grades": [0, 0, 0, 0, 1]
}
```
#### Специфичные поля шага SORT

* **`block.name`** : `"sorting"` — Тип шага. Для задачи на сортировку всегда `"sorting"`.

* **`block.source`** : Объект, содержащий данные для проверки ответа.

  * `options` : Массив объектов, каждый из которых представляет один элемент для сортировки.

    * `text` : Текст элемента (может содержать HTML-разметку, если включена опция `is_html_enabled`).

  * `is_html_enabled` : `true` — Разрешено ли использование HTML-разметки в тексте элементов.

* **`cost`** : `2` — Баллы за выполнение шага.
