### Шаг MATCH (задача на сопоставление)

В этом типе задач пользователю предлагается сопоставить элементы из левого столбца с элементами из правого столбца. Система автоматически проверяет правильность всех сопоставлений.

> **Общие поля** (`id`, `lesson`, `position`, `status`, `text`, `video`, `viewed_by`, `passed_by`, `discussions_count`, `num_grades`) описаны в разделе ["Текстовые шаги в Stepik"](https://stepik.org/lesson/2281192/step/1?unit=2315580). Здесь рассматриваются только поля, специфичные для задач на сопоставление.

#### Пример шага MATCH из API Stepik

```json
{
  "id": 9485452,
  "lesson": 2237157,
  "position": 2,
  "status": "ready",
  "block": {
    "name": "matching",
    "text": "<h2>Авторы и произведения</h2>\n<p>Кто автор произведения?</p>",
    "video": null,
    "options": {},
    "source": {
      "preserve_firsts_order": true,
      "is_html_enabled": true,
      "pairs": [
        {
          "first": "Муму",
          "second": "Тургенев И.С."
        },
        {
          "first": "Война и мир",
          "second": "Толстой Л.Н."
        },
        {
          "first": "Бородино",
          "second": "Лермонтов М.Ю."
        }
      ]
    }
  },
  "cost": 2,
  "viewed_by": 30,
  "passed_by": 25,
  "correct_ratio": 0.833,
  "discussions_count": 1,
  "num_grades": [0, 0, 0, 0, 2]
}
```

#### Специфичные поля шага MATCH
* **`block.name`** : `"matching"` — Тип шага. Для задачи на сопоставление всегда `"matching"`.

* **`block.source`** : Объект, содержащий данные для проверки ответа.

  * `pairs` : Массив объектов, каждый из которых задаёт одну пару для сопоставления.

    * `first` : Элемент из левого столбца (то, что нужно сопоставить).
    * `second` : Элемент из правого столбца (правильное соответствие).

   * `preserve_firsts_order` : `true` / `false` — Сохранять ли порядок элементов в левом столбце. Если `false` — элементы перемешиваются.

  * `is_html_enabled` : `true` — Разрешено ли использование HTML-разметки в тексте элементов.

 * **`cost`** : `2` — Баллы за выполнение шага.
